# 🏋️ Fitness App

A Flutter-based fitness application project designed to support fitness tracking and user activity management.

## 📌 Project Overview

Fitness App is a mobile application developed using Flutter and Dart. The project includes integrations and packages for authentication, cloud data storage, activity tracking, and progress visualization.

## 🛠️ Technologies Used

- **Flutter** – Cross-platform application development
- **Dart** – Programming language
- **Firebase Authentication** – Authentication integration
- **Cloud Firestore** – Cloud database integration
- **Pedometer** – Step-counting functionality
- **Shared Preferences** – Local data storage
- **Percent Indicator** – Progress visualization
- **UUID** – Unique identifier generation

## ✨ Project Components

The project dependencies support:
- User authentication
- Cloud database connectivity
- Physical activity and step tracking
- Progress indicators
- Local preference storage

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/dhanushv2007/Fitness_app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Fitness_app
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
